## Why this matters for the portfolio

Before this pass, the battle scene was already functional but still leaned toward a UI test scene. Adding visible battlefield units and command framing makes captures communicate a game scene faster, even before custom art is available.

This also keeps the workflow maintainable: the presentation is generated by `BattleSceneAutoBuilder`, not hand-edited scene YAML, so the look can be regenerated and validated after future changes.
