# 2026-05-28 — Batch 76: Chibi Pixel Standee Direction Pass

## Goal

Adapt the user's requested reference direction into the battle scene without copying the supplied image or any commercial character art.

The target feel is a fantasy RPG chibi pixel sprite sheet: oversized heads, compact bodies, crisp dark outlines, readable silhouettes, limited palettes, small weapons/accessories, and soft ground shadows.

## What changed

- Reworked the generated battlefield standees in `BattleSceneAutoBuilder.cs`:
  - Added original generated PNG sprite assets at `Assets/Art/Generated/chibi_hero_original.png` and `Assets/Art/Generated/chibi_enemy_original.png`.
  - Hero now uses a chibi pixel silhouette with a large outlined head, hair blocks, face/eyes, compact tunic, belt, cape, boots, sword, and soft shadow.
  - Enemy now uses a boss-like chibi silhouette with a larger head, dark hair side masses, robe/body blocks, glowing core, crown/gem, horn accents, tail accent, boots, aura, and soft shadow.
- Added `CreateSpritePanel(...)` / `LoadPixelSprite(...)` helpers so generated PNG sprites can be loaded as point-filtered Unity `Image` sprites from the scene builder.
- Updated `ValidateBattleTestScene` checks from the old tall placeholder standee requirements to the new chibi-proportion requirements.
- Updated `Docs/PortfolioShowcaseDraft.md` to document the new art direction and explain that this is an original procedural adaptation, not a copy of the reference image.

## Why this matters for the portfolio

The previous standees proved that the battle scene could show battlefield units, but their proportions still felt closer to abstract UI placeholders. This pass moves the presentation closer to an RPG character-driven screenshot: the viewer can immediately read hero vs enemy, weapon vs boss accessory, and party-character scale.

The work is still generated by editor code, which keeps the scene reproducible and testable. It also creates a clear bridge for later asset replacement: when real sprite sheets are available, the layout, silhouette scale, and validation expectations are already defined.

## Art direction notes

- Reference qualities to keep:
  - Chibi 2D RPG proportions.
  - Clear dark outline around body/head.
  - High-contrast accent colors.
  - Fantasy class/boss details readable at small size.
- Avoid:
  - Copying exact characters, poses, costumes, palettes, or monster designs from the reference.
  - Overloading the battlefield with too many small parts before core VFX readability is solved.
